## Overview

Completed as an independent study for my Graphic Communications minor at North Carolina State University. This project involved reverse engineering and modeling existing go-kart components using SolidWorks, with a focus on 3D CAD modeling, mechanical assemblies, and engineering documentation.

Individual components were modeled and assembled to recreate portions of the original go-kart. Part and assembly drawings were then produced to document component geometry and assembly relationships.

## Project Work

- Reverse engineered existing go-kart components and recreated them as 3D CAD models in SolidWorks.
- Developed SolidWorks assemblies to represent component relationships and mechanical configurations.
- Created detailed engineering drawings of individual parts and assemblies.
- Generated a rendering of the modeled assembly.
- Documented the project methodology and results in a final report.

## Tools and Skills

- **CAD Software:** SolidWorks
- **Methods:** Reverse Engineering, 3D Part Modeling, Assembly Modeling, Engineering Drawings
